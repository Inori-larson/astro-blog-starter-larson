## 为什么使用 MDX？

MDX 是一种特殊的 Markdown 方言，支持嵌入 JavaScript 和 JSX 语法。这让你能够[把 JavaScript 和 UI 组件混入 Markdown 内容](https://docs.astro.build/en/guides/markdown-content/#mdx-features)，实现交互式图表或提示框等功能。

如果你已经有用 MDX 编写的内容，希望这个集成能让你迁移到 Astro 变得轻而易举。
